## What it is
PlugAI-Trade is the book's free, open-source (Apache-2.0) companion application. It runs on the reader's own computer, opens in the browser at `localhost:8501`, and is a **research, planning, paper-trading and review lab**. It **never places real orders** — there is no order code in it at all. It is a productivity tool: it gathers data, computes numbers, and lets an AI model explain them.

- Repo: `github.com/plugai/plugai-trade` (book tag `book-v1.0`). Printed in the book as a short URL + QR.
- Install (one line): `uv tool install plugai-trade` then `plugai-trade start`. (Windows/macOS/Linux; uv downloads Python itself.) Alternative: `docker run -p 8501:8501 plugai/plugai-trade`.
- First-run wizard: detects RAM → suggests a local model via Ollama (≤8 GB: small 4B model; 16 GB: 9B model; ≥32 GB: larger model) → optional cloud key → sample data loaded → 10-second self-test.
- Command line:
  | Command | Does |
  |---|---|
  | `plugai-trade start` | Launch the dashboard |
  | `plugai-trade doctor` | Print versions, check data sources and models, "matches book edition ✓" |
  | `plugai-trade lesson 22` | Open the lesson for Chapter 22 |
  | `plugai-trade fetch nse-bhavcopy --date 2026-05-29` | Download one data file |
  | `plugai-trade mcp` | Run the read-only MCP server (for Claude Desktop / ChatGPT) |
  | `plugai-trade update` | Update app + dated reference tables |

## Global UI
- Left **sidebar** with sections (below). Top bar: **market switch** `IN | US`, **data status** (source + age, e.g. "Upstox · 2 min ago"), **AI status** (model name + 🔒 Local or ☁ Cloud badge), **cost meter** (₹/\$ this month).
- Every AI output has three buttons: **Explain**, **Show sources** (reveals the numbers/rows/pages it used), **Second opinion** (a fresh model reviews it adversarially).
- Every chart and backtest carries a **HYPOTHETICAL** watermark.
- Nothing the AI proposes is applied until the reader clicks **Accept**.
- Paper only: the word "order" appears only as "paper order".

## Data sources (Settings › Data Sources) — free only
Tiers shown in the UI: **No signup** · **Free key** · **Your broker**.
- No signup: `Synthetic` (offline default), `NSE bhavcopy` (India EOD), `BSE bhavcopy`, `AMFI NAV`, `yfinance` (personal use; US + .NS), `SEC EDGAR`, `Frankfurter FX`, `Crypto public (CCXT)`, `NSE/BSE announcements RSS`, `GDELT news`.
- Free key: `Alpaca` (US, paper account, IEX real-time), `FRED`, `Finnhub`, `Tiingo`, `Massive`.
- Your broker (India, read-only): `Upstox` (Analytics Token, ₹0), `Fyers`, `Angel One SmartAPI`, `ICICI Breeze` (₹0 with account); `Zerodha Kite`, `Dhan`, `Groww` (paid data plans).
- Every bar carries a provenance tag; disagreements >0.5% between sources are flagged.

## AI layer (Settings › AI Models)
Default local via Ollama; optional cloud keys (Gemini, Groq, OpenRouter, OpenAI, Anthropic, DeepSeek) through LiteLLM. Rule enforced in code: **the model explains numbers, it never computes them.** Output filter blocks buy/sell/target language on named securities.

## Python API (Builder track only; keep snippets short)
```python
from plugai_trade import data, backtest, options, journal, ai
bars  = data.get("NIFTY", market="IN", start="2025-01-01", end="2026-05-29")   # DataFrame (Polars)
spec  = backtest.rules("Buy when close > 50-day average; exit below 20-day average")
res   = backtest.run(spec, bars, costs="IN-equity-delivery")
res.report()          # Report Card
opt   = options.leg("NIFTY", kind="call", strike=25000, expiry="weekly", side="buy")
j     = journal.load("zerodha_tradebook.csv")
ai.explain(res)       # narration with sources
```
